Project name: Simple Product Manager

Short description:
A minimal Flask app to add, view, search, and delete products using SQLite and Flask-SQLAlchemy.

Setup commands (macOS / Linux):

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

Setup commands (Windows PowerShell):

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

Setup commands (Windows CMD):

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Run command:

python app.py

GitHub repository URL: https://github.com/b-hommik/python_Simple_Product_Manager
