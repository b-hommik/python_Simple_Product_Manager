Project name: Simple Product Manager

Short description:
A minimal Flask app to add, view, search, and delete products using SQLite and Flask-SQLAlchemy.

Setup commands (macOS / Linux):

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

Run command:

python app.py
